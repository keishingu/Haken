使い方とサポート

Hakenは現在、配布準備中です。公開後の導入方法もこのページに掲載します。

基本の使い方 ↓コマンドライン ↓困ったとき ↓

動作環境: macOS 15以降。ダウンロード可能な公開版はまだありません。

基本の使い方

  1. Hakenを起動し、Slotsでスロットを選びます。
  2. Choose…からApplicationまたはGoogle Chrome Profileを選びます。
  3. スロットのTestで動作を確認します。その後、割り当てたショートカットを押します。

番号キーは1〜9と0の10個です。Settings → Shortcut keysで、全スロットに適用するパターンを選びます。

  • ⌥ + Number keys（⌥1〜⌥0）
  • ⌥ + Function keys（⌥F1〜⌥F10）
  • ⌘ + Number keys（⌘1〜⌘0）
  • ⌘ + Function keys（⌘F1〜⌘F10）
  • Function keys（F1〜F10）

割り当てたスロットのショートカットはHaken用に予約されます。空のスロットは前面のアプリで通常どおり使えます。

Chromeプロファイル

Google Chromeを起動してから、Slots画面でアクセシビリティ未許可ならEnable Chrome Profiles…を選び、macOSのSystem SettingsでHakenを許可してください。許可後にRefresh Chrome Profilesを選ぶと、登録できるプロファイルが表示されます。HakenはChromeのメニューバーにあるプロファイル切り替え項目を操作します。

許可を使うのはChromeプロファイルの取得と切り替えです。通常のアプリ切り替えにはアクセシビリティ許可は必要ありません。Chromeのウィンドウが別のデスクトップやフルスクリーンにある場合、切り替え後の最終的な配置まではHakenが確認できないことがあります。

HUDで割り当てを確認する

Settings → Switch feedback → HUDを選ぶと、⌥または⌘を長押ししたときに割り当てを表示できます。修飾キーを使わないFunction keysパターンでは表示されません。

配布後のインストール

公開後はリリースからmacOS用DMGを取得し、ディスクイメージを開いてHakenをアプリケーションフォルダへ移動する手順をここに掲載します。現時点では公開バイナリがないため、インストール操作はできません。

アップデートは自動では行われません。新しい版をリリースページで確認し、手動で更新してください。

コマンドライン（任意）

アプリのSettings → Command Line → Install haken Commandから、アプリに同梱されたコマンドへのリンクを ~/.local/bin/haken に作成します。シェル設定は変更しません。コマンドを使うには ~/.local/bin がPATHに含まれている必要があります。

haken slot list
haken slot activate 2
haken chrome profiles --json
haken doctor --json

CLIはHakenアプリとユーザー専用のローカルソケットで通信します。スロットへの永続的な変更には確認が必要です。

困ったとき

キーを押しても切り替わらず、文字が入力されます

パスワード欄などでmacOSのSecure Inputが有効になると、OptionのみのグローバルショートカットがHakenに届かない場合があります。入力欄からフォーカスを移すか、そのアプリを終了して再度お試しください。CLIが利用できる場合は haken slot activate 2 のように直接切り替えられます。

Chromeプロファイルを取得できません

Chromeを起動してください。アクセシビリティ未許可ならEnable Chrome Profiles…を選び、macOSのSystem Settings → Privacy & Security → AccessibilityでHakenを許可して戻ります。許可済みの場合はRefresh Chrome Profilesを実行してください。

問い合わせに診断情報を添えたい

Diagnostics → Copy Diagnosticsでコピーできます。この診断情報にはChromeプロファイル名、アプリのパス、URL、タブ名、キー入力履歴は含まれません。GitHubのIssueでお問い合わせください。公開Issueには個人情報を記載しないでください。
