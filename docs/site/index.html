QUESTIONS

よくある質問

どのmacOSで使えますか？+

macOS 15以降に対応しています。

アクセシビリティ許可は必要ですか？+

通常のアプリ切り替えには不要です。Chromeプロファイルを登録・切り替えるときだけ必要です。

アプリの情報やキー入力は送信されますか？+

Hakenアプリは自動で通信せず、URLやタブ名、キー入力履歴を収集しません。保存内容などはプライバシーをご覧ください。

ダウンロードできますか？+

現在、配布準備中です。公開後のインストール方法はサポートページに掲載します。
