アプリとChromeプロファイルを、いつも同じキーで呼び出す。

⌥1でTerminal、⌥2で仕事用Chrome。Hakenなら、よく使うアプリやChromeプロファイルにキーを割り当てて、直接切り替えられます。

macOS 15以降 · メニューバー常駐

GitHubで見る 使い方

配布用DMGは準備中です。

Chromeの仕事用と個人用に、それぞれのキーを。

仕事用と個人用を、別々のキーに登録できます。Chromeのメニューでプロファイルを選び直す操作も、⌥2や⌥4で済みます。

Chromeを起動し、Hakenにアクセシビリティを許可してお使いください。通常のアプリ切り替えだけなら、この許可は不要です。

よく使うアプリを、10個のキーに。

⌘Tabの並び順が変わっても、Hakenに登録したキーは変わりません。起動中のアプリを前面に表示し、起動していなければ起動します。

初期設定は⌥＋数字。⌘やFキーを使うパターンにも変更できます。選んだパターンは10枠すべてに適用され、未登録のキーは、いま使っているアプリにそのまま届きます。

⌥・⌘を使うパターンでは、長押しで割り当て一覧を表示できます。表示の有無は設定で選べます。

コマンドやAIエージェントからも切り替えられます。

同梱のhakenコマンドを使えば、ターミナルから切り替えや登録ができます。AIエージェントに操作手順を伝えるSkillも付属しています。

haken slot activate 2
haken chrome activate "仕事用"

「仕事用」はChromeのプロファイル名の例です。

コマンド・Skillの使い方

対応環境と配布について

Haken単体で動作します。Karabinerやスクリプトの準備は必要ありません。設定はMac内に保存され、アプリから自動送信されることはありません。

現在はGitHubでソースコードとビルド手順を公開しています。
